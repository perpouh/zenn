# AIを使ってパッケージ設定ファイルのコメントを日本語化する

## 経緯

個人製作アプリに[Laravel-Markdown](https://github.com/GrahamCampbell/Laravel-Markdown)を導入したい

以下は[インストール手順の一部](https://github.com/GrahamCampbell/Laravel-Markdown?tab=readme-ov-file#configuration)

```sh
/var/www/html # php artisan vendor:publish

 ┌ Which provider or tag's files would you like to publish? ───────────────┐
 │ Search...                                                               │
 │ Markdown                                                      │
 └──────────────────────────────────────────────────────────────┘

   INFO  Publishing assets.  

  Copying file [vendor/graham-campbell/markdown/config/markdown.php] to [config/markdown.php] ................................................. DONE
```

→[config/markdown.php](https://github.com/GrahamCampbell/Laravel-Markdown/blob/16.0/config/markdown.php)には丁寧にコメントが添えられているが英語つらい  
→AIに翻訳させてみる

## やったこと

(私'ω')< @markdown.php のコメント部分だけを日本語に翻訳して書き換えてください  
(AI'ω')< かりこまり

## 生成されたもの抜粋

```
<?php

declare(strict_types=1);

/*
 * This file is part of Laravel Markdown.
 *
 * (c) Graham Campbell <hello@gjcampbell.co.uk>
 *
 * For the full copyright and license information, please view the LICENSE
 * file that was distributed with this source code.
 */

return [

    /*
    |--------------------------------------------------------------------------
    | ビュー統合の有効化
    |--------------------------------------------------------------------------
    |
    | このオプションは、ビュー統合が有効かどうかを指定します。これにより、
    | マークダウンビューを記述し、HTMLとしてレンダリングできます。現在
    | サポートされている拡張子は以下の通りです：".md", ".md.php", ".md.blade.php"。
    | 他のパッケージと競合する場合は、この統合を無効にすることができます。
    |
    | デフォルト: true
    |
    */

    'views' => true,

    /*
    |--------------------------------------------------------------------------
    | CommonMark拡張機能
    |--------------------------------------------------------------------------
    |
    | このオプションは、自動的に有効になる拡張機能を指定します。
    | ここに拡張機能のクラス名を指定してください。
    |
    | デフォルト: [
    |              League\CommonMark\Extension\CommonMark\CommonMarkCoreExtension::class,
    |              League\CommonMark\Extension\Table\TableExtension::class,
    |          ]
    |
    */

    'extensions' => [
        League\CommonMark\Extension\CommonMark\CommonMarkCoreExtension::class,
        League\CommonMark\Extension\Table\TableExtension::class,
    ],
```
